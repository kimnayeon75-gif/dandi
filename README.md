# 단디 동구 부동산 브리핑

대구광역시 동구 아파트 시장을 고객에게 브리핑하기 위한 반응형 부동산 대시보드입니다.

## 주요 기능

- 동별 아파트 목록과 매매·전세·월세 Top 10
- 주간·월간·사용자 지정 기간 조회
- 선택 단지 지도와 최근 실거래 정보
- 추천매물 추가와 입지분석
- 교통·학군·상권·생활환경·개발계획 요약

## 로컬 실행

`index.html`을 열거나 정적 웹 서버의 루트에서 실행합니다.

> 공개 저장소에는 API 키가 포함되어 있지 않습니다. GitHub Pages에서는 안전한 브리핑 데이터가 표시됩니다.
