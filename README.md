# 단디 동구 부동산 브리핑

국토교통부 아파트 실거래 신고자료를 바탕으로 대구광역시 동구 시장을 고객에게 브리핑하기 위한 반응형 대시보드입니다.

## 주요 기능

- 동별 아파트 목록과 매매·전세·월세 Top 10
- 주간·월간·사용자 지정 기간 조회
- 선택 단지 지도와 최근 실거래 정보
- 추천매물 추가와 입지분석
- 교통·학군·상권·생활환경·개발계획 요약
- 휴대폰과 PC에 설치 가능한 PWA 앱

## 데이터

- 지역코드: 대구광역시 동구 `27140`
- 범위: 최근 12개월 매매·전세·월세 신고자료
- 출처: [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/)
- `data/market-index.json`의 `updatedAt`은 배포 자료의 갱신 시각입니다. 화면은 한국시간 갱신 시각, 거래 파일에 담긴 최신 계약일, 사용자가 선택한 조회기간을 각각 표시합니다.
- 주간과 월간 조회는 최신 계약일을 포함한 최근 7일과 30일입니다.
- 신고 및 해제에 따라 집계값은 변동될 수 있습니다.

## 배포 데이터 갱신

대시보드는 저장소의 월별 JSON을 읽습니다. 화면에서 조회 조건을 변경하면 해당 파일을 기준으로 재집계합니다.

1. 공식 매매·전월세 자료에서 지역코드 `27140`의 최신 월과 지연 신고·해제가 반영될 수 있는 이전 월을 다시 수집합니다.
2. 매매 해제 거래를 처리한 기준을 기록하고, 월별 거래 건수를 원자료와 대조합니다.
3. 월별 JSON과 목록 파일의 월·건수·자료 갱신 시각을 같은 커밋에서 갱신합니다. 누락되거나 건수가 다른 월이 있으면 새 자료를 배포하기 전에 확인합니다.

## 로컬 실행

`index.html`을 열거나 정적 웹 서버의 루트에서 실행합니다.

> 공개 저장소에는 API 키가 포함되어 있지 않으며, 조회 결과 데이터만 배포합니다.
